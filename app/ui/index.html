Yazı Düzeltme Kısayolu

                            
WhatsApp'ta bir mesaj yazarken (henüz göndermeden) bu kısayola basınca, yazı kutusunun altında iki seçenek çıkar: "Düzeltme Önerileri" düzeltilmiş/resmi/samimi varyantlar önerir, "Dile Çevir" ise seçtiğin dile çevirir.

                            

                                
                                

                                    
                                    
                                

                            

                            
                            
Açıkken, WhatsApp'ta yazarken bir süre durduğunda kısayola basmana gerek kalmadan yukarıdaki "Düzeltme Önerileri / Dile Çevir" paneli otomatik açılır.

                            
                            
Açıkken, yazı düzeltme gibi yardımcı özellikler önce yerelde kurulu bir modeli dener (daha hızlı, cloud kotanı harcamaz) — model uygun bir sonuç üretemezse (ör. yanlış dilde yazarsa) otomatik olarak ayarlı asıl modele döner. Kapalıyken doğrudan ayarlı modeli kullanır.

                Ollama API Anahtarı
                
            

            

                
                
            

            

                

                    
Ollama Cloud hesabından aldığın API anahtarını buraya yapıştır.

                    

                        
                    

                    

                    
                

                

                    

                        1. ollama.com adresine git ve giriş yap

                        2. Sağ üstten hesap menüsü → Settings'e git

                        3. API Keys sekmesinde "Create API Key" ile yeni bir anahtar oluştur

                        4. Anahtarı kopyala ve "Anahtar Gir" sekmesine yapıştır
